# Phonetic Respelling & Technical Dictionary for Kokoro

Kokoro uses `misaki` with `espeak-ng` and `en_core_web_sm` for English G2P. Certain machine learning and computer science terms require phonetic respelling in script texts to avoid awkward pronunciations:

| Written Term | Recommended Respelling for Narration | Pronunciation Target |
|---|---|---|
| **ReLU** | `ray-loo` | /ˈreɪ.luː/ |
| **Epoch / Epochs** | `eh-pock` / `eh-pocks` | /ˈɛ.pɒk/ |
| **Backpropagation** | `back-propagation` | /ˈbæk.prɒp.əˈɡeɪ.ʃən/ |
| **Loss ($\mathcal{L}$)** | `the loss function` | (spell out rather than single letter) |
| **$\eta$ (Eta / Learning rate)**| `the learning rate, eta` | (never leave raw Greek letters) |
| **SQL** | `sequel` or `S-Q-L` | (depending on context preference) |
| **PostgreSQL** | `post-gres Q-L` | /ˈpoʊst.ɡrɛs.kjuː.ɛl/ |
| **Kubernetes / k8s** | `koo-ber-net-ees` | /kuː.bərˈnɛ.tiːz/ |
| **LaTeX** | `lay-tek` | /ˈleɪ.tɛk/ |
| **API** | `A-P-I` | /eɪ.piː.aɪ/ |
| **FIFO / LIFO** | `fie-foe` / `lie-foe` | /ˈfaɪ.foʊ/ |
| **JSON** | `jay-sahn` | /ˈdʒeɪ.sɒn/ |
| **NaN** | `not a number` | (clearer than "nan") |
