# Color Palettes for Motion Graphics

Use these calibrated hex palettes to ensure high contrast, accessibility, and visual hierarchy.

> [!IMPORTANT]
> **Default Theme Invariant:** Unless explicitly requested by the user or project brief, all motion graphics compositions default to a **lighter background** (warm ivory, off-white, or clean cream `#FBFBFA` / `#F5F3EF` / `#F4EFE6`). A lighter background does NOT mean dull or monochromatic — it is paired with rich, warm, punchy, and saturated contrast accents (vermilion/terracotta, electric ultramarine, marigold amber, emerald, and charcoal typography) inspired by top reference frames. Dark palettes are strictly opt-in.

---

## 1. Primary Default Light Themes

### Palette 1: "Warm Ivory & High-Contrast Vibrant" (Workspace Default)
*Best for: Technical explainers, systems architecture, economics, science, general motion graphics.*

- **Canvas Background:** `#FBFBFA` (warm ivory off-white; clean, easy on the eyes)
- **Panel / Surface Card:** `#FFFFFF` (pure white, with border `1px solid rgba(0, 0, 0, 0.08)` and subtle shadow `0 8px 24px rgba(0, 0, 0, 0.05)`)
- **Primary Typography:** `#111827` (deep crisp obsidian charcoal; > 15:1 contrast against canvas)
- **Secondary Typography:** `#4B5563` (refined slate body text; > 7:1 contrast)
- **Signal / Hero Accent:** `#E11D48` (vibrant vermilion rose / punchy red)
- **Energy / Flow / Highlight:** `#F59E0B` (warm marigold amber / gold)
- **Structure / Logic / Tech:** `#1D4ED8` (electric ultramarine cobalt blue)
- **Success / Positive Metric:** `#059669` (rich emerald green)
- **Warning / Alert:** `#EA580C` (international orange)
- **Grid / Field Lines:** `rgba(0, 0, 0, 0.06)` or `#E5E7EB`

---

### Palette 2: "Editorial Paper & Terracotta" (Studio Editorial-Light)
*Best for: Journalistic essays, explainers, craft, lifestyle, data narratives.*

- **Canvas Background:** `#F4EFE6` (warm newsprint paper)
- **Secondary Surface:** `#EBE3D4` (warm paper tint)
- **Primary Typography:** `#1E1B16` (warm dark ink; 15.0:1 contrast)
- **Secondary Typography:** `#5B5347` (warm muted ink; 6.6:1 contrast)
- **Hero Accent:** `#B8432A` (terracotta vermilion)
- **Secondary Accent:** `#2F5D50` (deep pine green)
- **Tertiary Accent:** `#D9A441` (warm ochre gold)
- **Highlight Tint:** `rgba(217, 164, 65, 0.42)`
- **Rule Lines:** `#CFC5B3`

---

### Palette 3: "Swiss Modern High-Contrast"
*Best for: Bold typography, product teasers, minimal UI demos, data-dense infographics.*

- **Canvas Background:** `#F8F9FA` (crisp modern light grey)
- **Panel / Surface:** `#FFFFFF` (pure white with `border: 1px solid #E5E7EB`)
- **Primary Typography:** `#09090B` (pitch black; maximum punch)
- **Secondary Typography:** `#64748B` (cool neutral slate)
- **Signal Pop 1:** `#FF4500` (international safety orange / vermilion)
- **Signal Pop 2:** `#2563EB` (vibrant blue)
- **Positive Accent:** `#10B981` (mint emerald)
- **Negative Accent:** `#EF4444` (crimson)

---

### Palette 4: "Cream & Signal Orange" (Reference Corpus Study: ref-92c / ref-0bf)
*Best for: Dynamic kinetic typography, chaptered explainers, high-impact cards.*

- **Canvas Background:** `#F8F6F0` (warm cream field)
- **Hero Contrast Field:** `#0A0A0E` (deep black contrast panels for figure-ground swaps)
- **Primary Accent:** `#F85838` (electric vermilion orange)
- **Secondary Accent:** `#2838F8` (ultramarine royal blue)
- **Tertiary Accent:** `#F8E8E8` (soft blush tint)
- **Primary Text:** `#0A0A0E` on cream, `#FFFFFF` on dark contrast cards

## 2. Optional Dark Themes (Strictly Opt-In When Brief Asks For It)

### Palette A: "Dark Tech"
*Best for: Terminal HUDs, cyber security, hardware internals when dark mode is explicitly briefed.*

- **Canvas Background:** `#080C14` (primary dark void)
- **Panel / Surface:** `#0D1117` with border `rgba(255, 255, 255, 0.08)`
- **Input / State A:** `#58A6FF` (electric blue), glow: `rgba(88, 166, 255, 0.35)`
- **Processing / Hidden Layers:** `#E3B341` (amber / warm gold)
- **Target / Output / Success:** `#3FB950` (emerald green)
- **Error / Loss / Gradient:** `#F85149` (crimson) to `#FF9500` (safety orange)
- **Primary Typography:** `#F0F6FC`
- **Secondary Typography:** `#8B949E`

---

### Palette B: "Cyber Cyan"
*Best for: Cyber defense, futuristic networking protocols.*

- **Canvas Background:** `#050914`
- **Primary Accent:** `#00F2FE` (neon cyan)
- **Secondary Accent:** `#4FACFE` (deep sky blue)
- **Warning / Alert:** `#FF007F` (neon magenta)
- **Text Primary:** `#FFFFFF`
- **Text Secondary:** `#7D93B2`

---

### Palette C: "Quantum Violet"
*Best for: Quantum physics, astrophysics, deep space theory.*

- **Canvas Background:** `#090714`
- **Primary Particle / Wave:** `#A855F7` (violet)
- **High Energy Accent:** `#EC4899` (electric pink)
- **Cosmic Light Accent:** `#38BDF8` (starlight blue)
- **Text Primary:** `#FDF4FF`
- **Text Secondary:** `#A1A1AA`
