# Source library

Books and other long-form sources we use to find film subjects. Each source has its own folder with a canonical JSON record (bibliography, rights, provenance and a per-item index) and a README rendered from that record.

These are finding aids, not research. A film built on any of these sources still goes through Stage 0 research (`technical-researcher`, `research.json`), working from the primary texts. A copyrighted source's prose and illustrations are never quoted, adapted or traced.
